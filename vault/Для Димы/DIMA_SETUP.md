# DIMA_SETUP — как обновлять мод и читать заметки

Здесь две вещи: обновлять мод одной кнопкой в лаунчере и открыть заметки по проекту.
Ничего собирать вручную не нужно.

---

## Обновить мод

Обновление устроено так: я выкладываю новую сборку, ты жмёшь в лаунчере одну кнопку —
и всё скачивается само. Файлы пересылать больше не надо.

### Первый раз — установка

1. Поставь **Prism Launcher**
2. Нажми **`Добавить экземпляр`** (`Add Instance`)
3. Слева выбери **`Импорт`** (`Import from zip`) и вставь в поле эту ссылку:

```
https://github.com/iBioCat/Silverleos/releases/latest/download/silverleos.mrpack
```

4. Жми `OK` — Prism сам скачает нужную версию игры, загрузчик, библиотеки и мод
5. Запусти. При первом старте он ещё докачает Java, это нормально

### Первый раз — включить кнопку обновления

Один раз надо показать лаунчеру, откуда брать новые версии.

1. Правой кнопкой по инстансу → **`Изменить`** (`Edit`)
2. В списке слева выбери вкладку **`Modrinth`**
3. Там будет поле **`URL:`** — вставь в него **ту же самую ссылку**, что и при установке
4. Закрой окно

Ссылка запоминается сама, сохранять ничего не нужно.

> [!tip] Проверь, что вкладка `Modrinth` на месте
> Она появляется только если инстанс создан импортом по ссылке из шага выше.
> Если вкладки нет — значит инстанс создавали как обычный, вручную. Тогда просто удали его
> и поставь заново по инструкции, миров там всё равно ещё нет.

### Дальше — само обновление

Когда я скажу, что вышла новая версия:

1. Правой кнопкой по инстансу → **`Изменить`** → вкладка **`Modrinth`**
2. Нажми **`Update Pack`**
3. Дождись окончания и запускай игру

Всё. Мод, библиотеки и версия игры подтянутся сами, старые файлы Prism уберёт.

> [!warning] Может появиться предупреждение про источник
> Prism спросит, доверяешь ли ты ссылке — это стандартная проверка для любого адреса,
> который не с CurseForge или Modrinth. Соглашайся, это наш GitHub.

> [!info] Миры и настройки не пропадут
> Обновление трогает только моды и служебные файлы. Сохранённые миры, скриншоты
> и настройки управления остаются на месте.

### Посмотреть существо в игре

Создай любой мир, включи читы. Яйцо призыва лежит во вкладке Spawn Eggs, либо в чат:

```
/summon silverleos:silverleos
```

> [!tip] Быстрый просмотр правок
> Если я дам тебе не готовую сборку, а папку проекта — модель можно обновлять на лету:
> сохраняешь файл и жмёшь в игре `F3 + T`, модель перезагрузится без перезапуска.
> Об этом договоримся отдельно, если понадобится.

## Открыть заметки по проекту

Заметки — это Obsidian-хранилище: дневник разработки, описание существа, идеи по механикам.

### Первый раз

1. Поставь **Obsidian** и **GitHub Desktop**
2. В GitHub Desktop: `File` → `Clone repository` → вкладка `URL`
3. Вставь адрес:

```
https://github.com/iBioCat/Silverleos.git
```

4. Выбери папку, куда сохранить, и жми `Clone`
5. Открой **Obsidian** → `Open folder as vault`
6. Выбери папку **`vault`** внутри скачанного проекта

> [!danger] Выбирай именно `vault`
> Если открыть папку проекта целиком, Obsidian начнёт считать хранилищем весь проект и
> насоздаёт заметок где попало. Нужна именно вложенная папка `vault`.

Начинай с `Home.md` — там оглавление и статус проекта.

### Дальше

Чтобы подтянуть свежие заметки — в GitHub Desktop нажми **`Pull origin`** (сверху).
Больше там ничего нажимать не нужно: свои файлы ты присылаешь мне напрямую, в git ничего
отправлять не надо.

## Если что-то не работает

**Нет вкладки `Modrinth` в настройках инстанса.** Инстанс создан не импортом по ссылке.
Удали и поставь заново по инструкции выше.

**`Update Pack` ругается или ничего не качает.** Проверь, что в поле `URL` вставлена ссылка
целиком, без пробелов и переносов строки.

**Существо не появляется по команде.** Проверь, что в мире включены читы.

**Что-то другое.** Просто напиши мне — не трать время на разбирательства.
