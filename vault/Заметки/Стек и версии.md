# Стек и версии

Все версии зафиксированы в `gradle.properties` — это единственный источник правды. В `build.gradle`
они подставляются через `${project.x}` и хардкодить их там нельзя.

| Компонент | Версия | Где проверить свежую |
| --- | --- | --- |
| Minecraft | 26.1.2 | `https://meta.fabricmc.net/v2/versions/game` |
| Fabric Loader | 0.19.3 | `https://meta.fabricmc.net/v2/versions/loader` |
| Fabric API | 0.155.2+26.1.2 | maven.fabricmc.net |
| Fabric Loom | 1.17-SNAPSHOT (резолвится в 1.17.19) | maven.fabricmc.net |
| GeckoLib | 5.5.2 | Cloudsmith GeckoLib maven |
| Gradle | 9.5.1 | обёртка в `gradle/wrapper` |
| Java | 25 | скачивается toolchain'ом |

## Маппинги

Yarn для 26.x **не выпускается** — последняя версия Yarn это 1.21.11. Проект собирается на
официальных маппингах Mojang, и Loom подставляет их сам. В блоке `dependencies` не должно быть
строки `mappings` вообще.

## GeckoLib: координаты сменились

```groovy
// было в 4.x и раньше
software.bernie.geckolib:geckolib-fabric-<mc>:<ver>

// стало в 5.5+
com.geckolib:geckolib-fabric-26.1.2:5.5.2
```

Репозиторий тот же — `https://dl.cloudsmith.io/public/geckolib3/geckolib/maven/`.

> [!tip] Как узнать реальный API, а не угадывать
> У GeckoLib публикуется `-sources.jar`. Скачать его и посмотреть исходники — самый быстрый способ
> увидеть настоящие сигнатуры вместо устаревших примеров из интернета.

## Java 25 без установки

JDK 25 на машине нет и ставить его не нужно. В `settings.gradle` подключён плагин
`org.gradle.toolchains.foojay-resolver-convention`, а в `build.gradle` задан toolchain на 25 —
Gradle скачивает JDK сам при первой сборке.

## Эталон конфигурации

Если что-то в сборке сломается после обновления — сверяться нужно с веткой `26.1.2` (или
актуальной) репозитория `FabricMC/fabric-example-mod`. Там лежит канонический `build.gradle`
для конкретной версии игры.
