# Silverleos — хранилище проекта

Fabric-мод для Minecraft 26.1.2. Главный герой — **Чешуйник (Silverleos)**, антропоморфный
хамелеон с камуфляжем. Делается на ModJam 2026 «Echoes of the Past».

> [!info] Как пользоваться
> Это Obsidian-хранилище лежит внутри репозитория, в папке `vault/`. Открывай саму папку `vault`
> как vault (Open folder as vault). Заметки коммитятся вместе с кодом, так что история решений
> живёт рядом с самим кодом.

## Где что лежит в репозитории

```
build.gradle, gradle.properties   — сборка и версии
src/main/java/...                 — общий код (сущность, регистрация)
src/client/java/...               — клиент (рендерер, модель GeckoLib)
src/client/resources/assets/...   — geo-модель, анимации, текстура, локали
.cursor/rules/                    — правила для ИИ-агента
vault/                            — это хранилище
```

